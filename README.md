# IDOI — Virtual Idol / Signal 01

IDOI 是一个以实时 3D、水晶折射、互动气泡与未来视觉档案构成的虚拟偶像网站。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## GitHub Pages

推送到 `ogen35/ogen35.github.io` 的 `main` 分支后，GitHub Actions 会自动构建并发布网站：

https://ogen35.github.io/

## 视觉系统

- 首屏：透明光学 D 模型、霓虹折射与光标避让气泡
- Profile：IDOI 角色设定与信号参数
- Live：虚拟演出与舞台视觉
- Archive：角色造型、海报与身份系统视觉数据库
